# WordRanker2

Находит все **суб-анаграммы** для каждого слова в словаре — то есть для каждого
слова A выводит все слова B, мультимножество букв которых является подмножеством
букв A.

## Алгоритм

### 1. Отпечаток мультимножества — 384-битная маска

Каждое слово кодируется в [384-битное целое число](./WordRanker/Int384.cs).
26 букв латинского алфавита умещаются в 384 бита по 10 бит на букву — каждое
10-битное поле хранит **количество** данной буквы в слове. Используйте
[`maxpprint.py`](./maxpprint.py), чтобы определить необходимую длину битового
поля для каждой буквы.

### 2. Группировка анаграмм

Слова с одинаковым ключом (анаграммы) группируются в запись `Anagram`. Каждая
группа имеет одну заранее вычисленную маску.

### 3. Проверка подмножества

Отношение подмножества проверяется одной битовой операцией:

```
(a.Mask | b.Mask) == a.Mask
```

> [!IMPORTANT]
> Если OR маски B с маской A не меняет A, значит каждая буква в B встречается не
> чаще, чем в A — B является суб-анаграммой A.

### 4. Оптимизация

Группы анаграмм сортируются по значению маски. Во вложенном цикле перебор B
останавливается досрочно при `b.Mask >= a.Mask` (так как маски big-endian,
бо́льшие маски не могут быть подмножествами).

### 5. Параллелизм

`Parallel.ForEach` и накопление на уровне потока позволяет избежать конкуренции
за блокировки. Готовые результаты по мере готовности записываются в файл на диск,
поскольку результат может занимать много памяти.

## Сборка и запуск

```shell
dotnet build
dotnet run --project WordRanker
```

Программа ожидает список слов (по одному слову на строку). См. раздел
«Настройка».

### Настройка

Измените [`WordRanker/Program.cs`](./WordRanker/Program.cs):

| Параметр | Что менять |
|---|---|
| Входной словарь | `dotnet run --project WordRanker -- path/to/words.txt`, или измените `GlobalConfiguration.InputFile` в [`WordRanker/GlobalConfiguration.cs`](./WordRanker/GlobalConfiguration.cs) |
| Выходной файл | Измените `GlobalConfiguration.OutputFile` в [`WordRanker/GlobalConfiguration.cs`](./WordRanker/GlobalConfiguration.cs) |
| Максимум потоков | Измените `GlobalConfiguration.MaxDegreeOfParallelism` в [`WordRanker/GlobalConfiguration.cs`](./WordRanker/GlobalConfiguration.cs) |

### Тесты

dotnet test
